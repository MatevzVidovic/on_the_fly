Stretch or proportional?

These settings tell a background graphic behind the label—such as a road-sign badge—how to resize to fit its text.

OptionWhat it does
StretchAdjusts width and height independently to fit the text. A square background can become a wide rectangle around a long label.
ProportionalEnlarges the background while keeping its original width-to-height ratio. A square stays square, leaving more empty space above and below a long label.

The letters keep their font size and shape. This setting does not control text scaling with map zoom or PDF paper size. GeoServer reference

What this means in LIFT

For ordinary text labels, expect no visible difference. In the inspected LIFT code, the dropdown sends this option to GeoServer, but the label generator does not add a background graphic for it to resize.

To make the text larger, change the label’s font size. The halo/outline around the letters is a separate setting.

Code evidence

The dropdown stores graphic-resize in EditLabel.vue. generateLabel() in GeoserverXMLGenerator.php writes the vendor option, but creates no label Graphic. The no-visible-change conclusion is based on this code path; custom SLD styles with a label graphic can use the option.
