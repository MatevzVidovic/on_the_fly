Prepared units: where the property identity lives

pripis_enote_deli_stavb supplies building-part unit records, including del_stavbe_id. pripis_enote_deli_parcel supplies parcel-part unit records, including parcela_id. Each has its own id and id_rel_pr_datum. Existing code joins their IDs to pripis_vmxpd_x_enote.id_rel_prip_enota.

The prepared unit’s internal ID is different from its natural property ID. Preserve that distinction when building comparison keys.

Source: existing unit/result joins. Other-task aggregation in this file must not be copied as the complete 5757 grouping rule.

EV: confirmed tables and remaining questions

Final building-part values: ev_del_stavbe_enota has dst_sid, id_model, id_model_ver, numeric vrednost, bigint posplosena_vrednost and err_msg.

Final parcel-part values: ev_parc_enota has pc_mid, id_parc_enota, id_model, id_model_ver, delez_povrsine, both values and err_msg.

Historical candidates: ev_del_stavbe_enota_h_2025_danes and ev_parc_enota_h_2025_danes have valid_from, valid_to and date_change. Older history partitions also exist. The inspected building-part history table does not have id_model_ver, while the parcel history table does. Version correspondence requires investigation. Sampled current EV STZ id_model_ver is 1164, while an ISAM selected STZ version is 44; no equivalence is established. See Lesson 3.

Intermediate candidates: ev_dst_pripis_podatki_h and ev_parc_pripis_podatki_h contain model, identity, value, variable/factor fields and validity timestamps. Column presence is confirmed; mapping to ISAM meaning and parcel-component matching are not yet established.

Current final tables lack explicit validity columns, so they must not be assumed suitable for any requested historical date. Confirm the source update conventions and historical interval semantics.

Parcel final values must be aggregated independently on each side by date + parcel + model + version before joining.

Database column evidence · Bounded date/model checks. Queries were read-only and rolled back; no database changes were made.

Small glossary

Cutoff date / presečni datum: the common date represented by both sources; ISAM preparation selects property records valid then, rather than accumulating transactions.
Model version: the particular valuation rules used.
Calculated value: value before generalized rounding.
Generalized value: value after that rounding.
Delta: ISAM minus EV.
Natural property ID: the building-part or parcel identifier, distinct from an internal prepared-unit ID.
