Prepared units: where the property identity lives

pripis_enote_deli_stavb supplies building-part unit records, including del_stavbe_id. pripis_enote_deli_parcel supplies parcel-part unit records, including parcela_id. Each has its own id and id_rel_pr_datum. Existing code joins their IDs to pripis_vmxpd_x_enote.id_rel_prip_enota.

The prepared unit’s internal ID is different from its natural property ID. Preserve that distinction when building comparison keys.

Source: existing unit/result joins. Other-task aggregation in this file must not be copied as the complete 5757 grouping rule.

EV: tables named by the task, plus gaps

The task names ev_parc_enota for parcel-part values: vrednost and posplosena_vrednost. The exact EV building-part and intermediate source tables, historical-date selection and model/version mappings still need investigation. Do not invent them from the ISAM names.

Parcel final values must be aggregated independently on each side by date + parcel + model + version before joining.

Small glossary

Cutoff date / presečni datum: the common date represented by both sources.
Model version: the particular valuation rules used.
Calculated value: value before generalized rounding.
Generalized value: value after that rounding.
Delta: ISAM minus EV.
Natural property ID: the building-part or parcel identifier, distinct from an internal prepared-unit ID.
