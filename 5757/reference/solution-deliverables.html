What the solution must contain

Purpose: save a trustworthy ISAM/EV comparison for one cutoff date and expose intermediate evidence for eligible calculated differences.

Data to preserve

Kind of recordMeaningEssential contents
Existing calculation resultISAM’s answer for a prepared unit and model/date selection.Numeric calculated value, generalized value, errors and intermediate source evidence. Fix Lift and PostgreSQL precision.
New final comparisonOne property + date + model + corresponding version comparison, distinguished by unit type.Both values for each comparison, ISAM − EV deltas, separate statuses; parcel part counts/IDs, available area/share and aggregate level.
New intermediate comparisonOne compared canonical ingredient, linked to its final comparison.Key/group, both values, outcome/issues, source EV fields and applied translation rule.
New simple-rule configurationA definition of how an EV field maps into canonical ISAM meaning for a model/version.Source/target keys, conversion settings and version scope. Structural transforms belong in versioned SQL.
Run record (proposal)One execution with fixed scope/settings.Date, tolerance, rule versions, state and linked output. Supports isolated retries and completion publication.

Processing order

Date-row SFC → fix context and check readiness
 → read same-date ISAM/EV evidence
 → aggregate parcels on each side, then match
 → save separate calculated/generalized comparisons
 → select valid pairs with abs(delta_izr) > tolerance
 → translate EV ingredients, then compare
 → persist linked output and publish completion
 → Lift filters and detail drill-down

Implementation can live in one Python/SQL workflow. SQL handles bulk filtering, aggregation and comparison; Python coordinates. Keep unpaired and failed records visible. Do not treat missing values as zero.

Before calling it trustworthy

Confirm historical EV date semantics and model-version correspondence. Agree tolerance and parcel semantic keys. Show both parcel rounding alternatives until the rule is decided. Preserve untranslated or ambiguous evidence; never force parcel-part pairing.

Final generalized-only differences stay visible but normally do not cause intermediate comparison. Tolerance’s effect on final equality statuses still needs agreement.
