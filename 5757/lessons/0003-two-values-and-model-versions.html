Yes: this is the ISAM answer we compare with EV

The prepared unit describes what is being valued. The calculated-value row records what a selected model version calculated for it. Lift stores/displays that result; the calculation workflow produces it.

Keep these two records separate

pripis_enote_deli_stavb: a prepared building part and its inputs at the selected date—such as area and construction year.

pripis_vmxpd_x_enote: the result for that unit under a selected model/date combination. vrednost_izr is the calculated value before generalized rounding; vrednost_zaokrozena is the generalized value.

The same prepared property can be valued under different selections. Keeping inputs and calculation results separate lets each result identify the inputs and rules used.

Source: existing calculation writer. The task compares this ISAM result with EV; it does not ask us to replace EV’s calculation.

Database examples, not an established mapping: sampled EV parcel rows use STZ / id_model_ver 1164. A verified ISAM selection for 2026-01-01 uses STZ / verzija 44.

We cannot assume 1164 = 44, or assume that different numbers mean different business rules. EV’s identifier needs an authoritative interpretation and correspondence to the ISAM version.

What 5757 therefore needs

Find the authoritative EV model-version definition and establish which ISAM version represents the same valuation rules. Preserve both original identifiers and use their confirmed correspondence when comparing results. This may need a lookup or an explicitly agreed mapping; it has not yet been verified.

For historical dates, version evidence must belong to the chosen EV snapshot. The inspected building-part history table ev_del_stavbe_enota_h_2025_danes lacks id_model_ver, although the current table has it. The parcel history counterpart has it. Some sampled ZPS parcel rows also have a NULL version, whose meaning needs investigation.

Do not silently borrow today’s version for an old value. Missing version evidence should remain visible until the source convention or a reliable historical mapping is established.
